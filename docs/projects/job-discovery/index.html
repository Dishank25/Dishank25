Flutter Job Discovery

A related job-portal snapshot focused on skills onboarding, search filters, and the candidate’s application flow.

The candidate’s signup flow groups skills and subskills by domain. When looking for a role, the candidate can set location and work-experience filters, then open the job details.

This snapshot shares code with the Student & Recruiter Job Portal. Its candidate flow exposes a useful state transition: the job details screen listens for the application result while a dedicated BLoC handles the submission event. Live listings and submissions depend on the configured backend.

Flutter, Dart, BLoC, Dio
