Pet breed identification

An image API that returns an explicit unknown result when the model has low confidence.

I prototyped a service that accepts a pet photo and asks GPT-4o Vision for a structured prediction. I checked the image input, validated the model’s JSON, and mapped low reported confidence to an unknown result. A caller can handle that outcome directly instead of treating every prediction as a definite breed.
